Tags to Reports

Prototype. Tags become a filter in the Downtime report. Stop reasons, stop groups, operators and operator groups can carry tags.

SettingsCreate tags and give them to stop reasons, stop groups, operators and operator groups. Reports: DowntimeFilter downtime by tags from "+FILTER".

Try this

  1. Open Downtime. "+FILTER" → Tags → Cleaning. Only stops with Cleaning remain.
  2. Set "X-axis: Tags". One bar per tag, plus "Untagged". A stop counts in every tag it has.
  3. Set "X-axis: Stations" and "Split by: Tags".
  4. Add a Products filter next to Tags. Both apply.
  5. In Settings, give "Motor failure" the tag Cleaning. Back in Downtime, it now passes the filter.

Prototype settings: the button in the bottom-right corner, or H.
